Simulation study

Can a network
grow a memory?

We grow an artificial recurrent network from one cell, prune its connections during maturation, then freeze it and measure how much of a random input stream it retains.

Matched controls test whether activity-dependent pruning contributes to that memory after accounting for wiring cost and basic graph structure.

Methods

From cell growth to memory

  1. Grow

    Start with one artificial cell on a two-dimensional grid. Expand along the growth front and form a sparse, directed network with signed connections between nearby cells.

  2. Prune

    Rank connections by lagged coactivity at each source. Compare activity pruning with random pruning at the same source-and-distance quotas and target swaps that preserve degrees, incoming signs, and global wiring lengths by sign.

  3. Measure

    Freeze the recurrent weights. Fit a ridge readout for each network under the same protocol to recover earlier independent random bits, then score on a separate test stream. Bootstrap paired differences across growth seeds.

How to interpret the comparison

Delayed reconstruction measures how much past input is accessible to a fitted linear readout. This comparison estimates the effect of the tested pruning rule within the simulator. The shared leaky node dynamics can also retain recent inputs. Measuring the contribution of growth itself would require a circuit generated directly under the same geometric constraints.
